uGDS — User-Space GPU Direct Storage

uGDS is the first production-oriented user-space GPU Direct Storage library. The CPU constructs NVMe commands and the SSD DMAs data directly to/from GPU memory over PCIe, completely bypassing the kernel NVMe driver.

With a GDS-compatible API, uGDS achieves up to 5.3x higher bandwidth and 108x lower 4KB latency (5.2μs vs 561μs) compared to NVIDIA GDS. It supports both NVIDIA CUDA and AMD ROCm backends, and has been integrated as the storage backend for LMCache, delivering 2x TTFT reduction and 2x throughput improvement in vLLM end-to-end benchmarks.

CoPilotIO — CPU as a Co-pilot for GPU I/O

CoPilotIO enables GPU kernels to initiate on-demand storage access while CPU cores handle completion polling, freeing GPU resources for computation. Split submission/completion queues, hardware-barrier synchronization, and adaptive CPU–GPU co-polling coordinate I/O efficiently.

Compared with BaM, CoPilotIO reduces I/O-induced stalls by up to 55.5% and uses 50% fewer SMs to saturate GPU PCIe bandwidth. It improves application performance by up to 85% in evaluations including MoE inference and recommendation models.

GitHub Paper (OSDI 2026)

ShaperIO — Rethinking GPU I/O at Massive Scale

ShaperIO redesigns I/O scheduling, caching, and admission control for GPU-initiated storage access. It orders and merges concurrent requests to preserve write sequentiality, moves cache writeback off the critical eviction path, and regulates submissions to prevent SSD overload.

ShaperIO achieves up to 7.51× higher post-write read bandwidth in microbenchmarks and up to 2.54× end-to-end speedup across BFS, GNN training, and LLM inference with KV-cache offloading.

GitHub Paper (ATC 2026)
